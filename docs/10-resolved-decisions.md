| **DEC-23** | Инструмент модерации (BR-11) не определён | Для MVP — стандартный **Django admin** (изменение статуса произведения через админку). Кастомный UI модератора (очередь, кнопки Approve/Reject/Request changes, аннотации) отложен на V2. Сам флоу: автор отправляет произведение на проверку → статус `OnModeration` → модератор меняет на `Published`/`NotPublished` с комментарием → автор получает уведомление | [08](08-business-rules.md) |
| **DEC-24** | Верификация возраста 14-18 (BR-20) не определена | **Самодекларация:** возраст указывается полем `age` при регистрации (FR-AUTH-04) и подтверждается чекбоксом при подаче на конкурс (`confirm_age` в `contest_submit.html`). Никаких документов, паспортов или parental consent в MVP — это сознательный компромисс ради скорости запуска. Если в эксплуатации обнаружится массовый абьюз — пересмотреть в V2 | [05](05-functional-spec.md), [08](08-business-rules.md) |
| **DEC-25** | Левый sidebar на десктопе: для гостя содержал 3 декоративные ссылки, дублирующие hero/жинақтар главной | Sidebar **исключён**. В хедере главный вход в чтение — **Оқу** (`/catalog/`), конкурсы остаются отдельной ссылкой **Байқаулар**. Жанрлар — обзорная страница и секция главной, Жинақтар — отдельный editorial-раздел в footer. Личные разделы авторизованного (Кітапхана, Менің шығармаларым, Заявкалар) — через avatar-dropdown в хедере, а mobile-nav авторизованного поднимает Кітапхана. Правый рейл рендерится только если страница явно передала `has_right_rail=True`. Контейнер уменьшен с `max-w-[1440px]` до `max-w-[1280px]` | [07](07-layout-navigation.md) |
| **DEC-26** | Жанровая сетка (12 закрытых категорий) слишком грубая для дискавери — два «фэнтези» могут быть совсем разными произведениями | Введена **UGC-таксономия тегов** параллельно жанрам. До **10 тегов** на произведение; автор создаёт свободно (длина 2-30, kk/ru/lat). Каждый новый тег попадает в статус `pending`, модератор пост-фактум переводит в `accepted` (заходит в автокомплит для следующих авторов) или `rejected`. Часть паттернов в **блок-листе** — создание отклоняется inline. Жанры не меняются — теги их дополняют (second-order навигация). Модерация — в Django admin (DEC-23) | [11](11-tags.md) |
| **DEC-27** | `genre_detail` и `search_results` — 90% дубликат шаблона/view; планируемый `/tag/<slug>/` стал бы третьим клоном; невозможно комбинировать «жанр + тег» в одной выборке | Каталог унифицируется в **один движок** с тремя branded entry-страницами: `/search/?q=...`, `/genres/<slug>/`, `/tag/<slug>/` (canonical URLs сохраняются для SEO/sharing). Поверх — общий filter bar с chip-фильтрами + общий `_book_list` партиал. Комбинации работают через query-string: `/genres/triller/?tag=mektep`. **Коллекции (Жинақтар) НЕ объединяются** — это editorial curation (статический ручной выбор), отдельный content type. Они переиспользуют только `_book_list`-партиал. «Smart collections» (auto-include по условию) — кандидат на V2 | [11](11-tags.md) |
| **DEC-28** | Платформа поддерживает и серийные произведения, и цельные рассказы; если ориентироваться только на главы, авторам короткой/средней прозы неудобно публиковаться, а читателям сложно найти быстрое чтение | `Story` остаётся единым content type, но получает `format`: `single` = бір бөлімді шығарма (рассказ/ертегі/эссе/новелла, UI показывает цельный текст без оглавления) и `serial` = көп бөлімді шығарма (главы, оглавление, prev/next). Формат выбирает автор, он не вычисляется автоматически по `chapters == 1`, потому что serial может временно иметь одну главу. Каталог фильтруется по `format` и `length` | [13](13-product-culture.md) |
| **DEC-29** | DEC-04 фиксировал целевую архитектуру как сборщик (Vite/Next) + ES-модули + клиентский стор. Проект построен иначе, и ТЗ три месяца описывало продукт, которого нет | **DEC-04 отменяется.** Фактический стек: **Django 6 (серверный рендеринг шаблонов)** + **Tailwind CSS v4 через `@tailwindcss/cli`** (токены в `@theme` внутри `static_src/input.css`) + **Alpine.js 3.14** и **htmx 2.0** как self-hosted `<script>`. JS-сборщика, ES-модулей и клиентского стора **нет и не планируется** в MVP: интерактивность точечная (дропдауны, модалки, автокомплит тегов, quick-search), она не требует SPA. Из DEC-04 в силе остаются два пункта — self-hosted шрифты и единый источник токенов в CSS-переменных | [01](01-overview-architecture.md) |
| **DEC-30** | ТЗ описывало три отдельных экрана чтения (`Reading`, `Reading popover`, `Reading dark`); в реализации отдельного маршрута чтения нет | Чтение главы — **инлайн на странице произведения**, глава выбирается через `?chapter=N`. Отдельного маршрута `/story/<slug>/chapter/<n>/` не существует. Причина: у `format=single` оглавления нет вообще, и отдельный экран чтения для него был бы пустой обёрткой; а для `serial` переход на отдельный маршрут терял контекст произведения (аннотацию, теги, комментарии). Настройки чтения — поповер на той же странице, тёмная тема — одно из трёх значений `readerTheme`, а не отдельный экран | [05](05-functional-spec.md) |
| **DEC-31** | Подросток выбирает чтение по состоянию («хочу поржать», «когда всё тяжело», «страшное на ночь»), а не по жанру: жанр — язык библиотекаря, а не читателя. При этом главная вела навигацию жанрами (секция `genres_section` — чипы + скроллер, ~330px в середине страницы), а редакционные подборки, уже написанные настроенческим языком, лежали шестой секцией | **Первичный вход в чтение — жинақтар** (`/collections/`): они отвечают на вопрос «зачем читать сейчас», стоят в первом фолде главной и заменяют каталог во втором слоте mobile nav у гостя. Создаёт их **только редакция** — пользовательских подборок на портале нет и не планируется (личное хранение — «Кітапхана»); кнопка «Өз жинағыңды құру» удалена. **Жанр понижается до вывески**: полоса чипов сразу под hero (~44px, ведёт на `/genres/<slug>/`), скроллер произведений активного жанра и параметр `?genre=` на главной удалены. Цветовая система по `Genre.hue` не меняется — жанр остаётся на каждой обложке и в фильтре. **Теги показывают актуальное**: рядом с накопленным `usage_count` появился недельный `weekly_count` («Осы аптада»), страница тега открывается сортировкой `recent`. Новых таксономий не вводится: связь «настроение → произведения» — это `Collection.story_slugs`, которым владеет редакция | [05](05-functional-spec.md), [07](07-layout-navigation.md), [11](11-tags.md) |

## Закрытые UX-аудиты → результат

| Аудит | Главная находка | Что сделано в ТЗ |
|-------|-----------------|------------------|
| **Главная** | Три одинаковых ряда, нет редакторского голоса | Редакционная витрина: hero-конкурс, книга недели, коллекции, новые авторы, состояния гость/возвращающийся, цветные жанры (FR-HOME-*) |
| **Конкурсы** | Страницы конкурсов не существует, 5 разрозненных упоминаний | Полный модуль CONT: список, детальная, подача с чек-листом, мои заявки (FR-CONT-*, BR-22..43) |

| **Right rail** | Соцсети как костыль; школа упомянута 6 раз без страницы | Рейл = продуктовые блоки; соцсети в footer. Школа в MVP — **блок внешних ссылок** (модуль LINKS), не страница (DEC-02/DEC-22) |
