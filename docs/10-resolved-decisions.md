# 10 · Реестр принятых решений

Сводная таблица всех несогласованностей и открытых вопросов прототипа/аудитов, закрытых в этом ТЗ. Каждое решение — `DEC-NN`.

| # | Что было (проблема / несогласованность) | ✅ Принятое решение | Где описано |
|---|------------------------------------------|---------------------|-------------|
| **DEC-01** | Неясно, как пользователь становится автором | Регистрация даёт роль Читатель; роль Автор присваивается автоматически при создании первого произведения | [00](00-glossary-roles.md) |
| **DEC-02** | Аудиты: платформа гонит трафик в соцсети vs MVP-упрощение | MVP: чтение/произведения/конкурсы — на платформе; «Авторлар мектебі» (видео, вебинары, интервью, курсы) — внешние ресурсы, на сайте только блок ссылок | [01](01-overview-architecture.md) |
| **DEC-03** | Прототип на абсолютном позиционировании (px) | В продакшене — поток flex/grid, резиновая сетка; mobile/desktop = состояния одной верстки; +tablet 768px | [01](01-overview-architecture.md) |
| **DEC-04** | Babel-in-browser, UMD-React, `window.*`, CDN-шрифты | Сборщик (Vite/Next), ES-модули, self-hosted шрифты, слой данных | [01](01-overview-architecture.md) |
| **DEC-05** | Токены продублированы: CSS-vars + инлайн `rgb()` | Единый источник — CSS-переменные; инлайн-цвета запрещены | [02](02-design-system.md) |
| **DEC-06** | Два цвета действия: бирюзовый (desktop) и синий (mobile FAB) | Единый accent — бирюзовый `--teal`; синий — только информационный семантический | [02](02-design-system.md) |
| **DEC-07** | Счётчик непрочитанных — разные места | Единый красный `rgb(220,38,38)` в шапке и сайдбаре | [02](02-design-system.md) |
| **DEC-08** | Промо-баннер выбивается из палитры (жёлто-зелёный + красный) | Намеренный сигнальный акцент; вынесен в токены `--promo-*`, только для конкурсов | [02](02-design-system.md) |
| **DEC-09** | Шрифт Caveat в проде; иконки смешивают fill/stroke | Caveat исключён (3 шрифта + Georgia); иконки — единый outline, залитые только для активных состояний | [02](02-design-system.md), [04](04-component-library.md) |
| **DEC-10** | Disabled-состояния не проработаны | Обязательны для всех кнопок и полей | [02](02-design-system.md) |
| **DEC-11** | Состав жанров и их назначение произведению | Закрытый справочник 12 жанров; 1 основной + до 1 доп. | [03](03-genre-color-system.md), [08](08-business-rules.md) |
| **DEC-12** | OKLCH не поддерживается старыми браузерами | Добавить sRGB-fallback (36 значений) через `@supports` | [03](03-genre-color-system.md) |
| **DEC-13** | Валидация форм не системна | Единые InputValidated/TextAreaValidated: default/success/error + aria-describedby | [04](04-component-library.md) |
| **DEC-14** | Два компонента жанра: GenrePill (текст) и GenreChip (цвет) | Остаётся только GenreChip (OKLCH); GenrePill исключён | [04](04-component-library.md) |
| **DEC-15** | «Tabs that don't tab»: декоративные табы, всё отрендерено сразу (Story, Profile, mobile) | Анти-паттерн исключён; sticky scrollspy или честное переключение | [05](05-functional-spec.md), [07](07-layout-navigation.md) |
| **DEC-16** | Множество версий экранов (Home v1-v3, Story v1, и т.д.) | Каноничны только финальные версии; эксперименты в разработку не идут | [06](06-screens-flows.md) |
| **DEC-17** | Loading/Error состояния отсутствовали | Обязательны для всех data-зависимых экранов | [06](06-screens-flows.md) |
| **DEC-18** | Правый рейл отдавал функции сайта соцсетям | Рейл несёт продуктовые блоки; соцсети убраны в footer | [07](07-layout-navigation.md) |
| **DEC-19** | Соцсети в нескольких местах | Footer + блок «Авторлар мектебі»; контент смотрится вне платформы, видео не встраивается (MVP) | [07](07-layout-navigation.md) |
| **DEC-20** | Жанры — плоская текстовая полоса | Заменены цветными чипами OKLCH | [07](07-layout-navigation.md) |
| **DEC-21** | AI-декларация в подаче на конкурс не финализирована | Обязательный пункт чек-листа; без ответа работа не подаётся | [08](08-business-rules.md) |
| **DEC-22** | Школа авторов: страница с уроками vs упрощение MVP | Внутренняя страница школы (уроки/модули/инструкторы/прогресс) исключена; заменена блоком внешних ссылок — модуль LINKS. Аннулированы FR-SCHOOL-01…07 и BR-50…53 | [05](05-functional-spec.md), [08](08-business-rules.md) |
| **DEC-23** | Инструмент модерации (BR-11) не определён | Для MVP — стандартный **Django admin** (изменение статуса произведения через админку). Кастомный UI модератора (очередь, кнопки Approve/Reject/Request changes, аннотации) отложен на V2. Сам флоу: автор отправляет произведение на проверку → статус `OnModeration` → модератор меняет на `Published`/`NotPublished` с комментарием → автор получает уведомление | [08](08-business-rules.md) |
| **DEC-24** | Верификация возраста 14-18 (BR-20) не определена | **Самодекларация:** возраст указывается полем `age` при регистрации (FR-AUTH-04) и подтверждается чекбоксом при подаче на конкурс (`confirm_age` в `contest_submit.html`). Никаких документов, паспортов или parental consent в MVP — это сознательный компромисс ради скорости запуска. Если в эксплуатации обнаружится массовый абьюз — пересмотреть в V2 | [05](05-functional-spec.md), [08](08-business-rules.md) |

## Закрытые UX-аудиты → результат

| Аудит | Главная находка | Что сделано в ТЗ |
|-------|-----------------|------------------|
| **Главная** | Три одинаковых ряда, нет редакторского голоса | Редакционная витрина: hero-конкурс, книга недели, коллекции, новые авторы, состояния гость/возвращающийся, цветные жанры (FR-HOME-*) |
| **Конкурсы** | Страницы конкурсов не существует, 5 разрозненных упоминаний | Полный модуль CONT: список, детальная, подача с чек-листом, мои заявки (FR-CONT-*, BR-22..43) |
| **Story detail** | Декоративные табы, всё видно сразу | Sticky scrollspy, рекомендации вынесены вниз (FR-STORY-02/03, DEC-15) |
| **Right rail** | Соцсети как костыль; школа упомянута 6 раз без страницы | Рейл = продуктовые блоки; соцсети в footer. Школа в MVP — **блок внешних ссылок** (модуль LINKS), не страница (DEC-02/DEC-22) |

## Открытые вопросы для уточнения с заказчиком

Эти пункты требуют решения на старте разработки (не блокируют дизайн):

1. **Точные лимиты текста:** аннотация (предложено 250 знаков), биография — подтвердить.
2. **Политика модерации:** SLA проверки, кто модераторы, эскалация жалоб. *Инструмент = Django admin (DEC-23), но SLA и состав модераторов открыты.*
3. **Призовой фонд:** источник финансирования, механика выплат победителям.
4. **«Авторлар мектебі» в будущих версиях:** хранить ли видео/курсы на платформе позже (вне MVP); сейчас — только внешние ссылки.
5. **Монетизация:** вне текущего scope — зафиксировать, планируется ли (влияет на архитектуру).
6. **Планшетный брейкпоинт:** подтвердить 768px и поведение сайдбара на нём.
