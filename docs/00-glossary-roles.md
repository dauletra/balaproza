## 0.2 Роли пользователей

Платформа различает три роли. Отдельной роли «читатель» нет — любой авторизованный пользователь автоматически считается автором, даже если ещё не создал ни одного произведения.

### Гость (Guest, не авторизован)
Может просматривать публичный контент, но не взаимодействовать.

### Автор (Author, авторизован)
Базовая и единственная роль обычного пользователя. Присваивается сразу после регистрации. Включает в себя всё, что раньше относилось к «читателю» (чтение, лайки, комментарии, сохранение в библиотеку, подписки, жалобы) и все авторские возможности (доступ к авторскому кабинету `WRITE`, создание/редактирование/удаление своих произведений, подача на конкурс). Никаких отдельных действий, превращающих пользователя в автора, не требуется.

### Модератор / Редактор (Moderator)
Внутренняя роль. Проверяет произведения на модерации, формирует коллекции (жинақтар), курирует «Книгу недели» и редакционные подборки, управляет конкурсами и составом внешних ссылок «Авторлар мектебі».

## 0.4 Сущности и связи (упрощённая модель данных)

```
User (1) ──< (N) Story
Story (1) ──< (N) Chapter
Story (N) >── (1..2) Genre         // основной + дополнительный жанр
Story (N) >──< (N) Tag             // UGC-теги, до 10 (DEC-26, BR-TAG-01)
Story (1) ──< (N) Comment
Comment (1) ──< (N) Comment        // ответы (1 уровень вложенности)
User (1) ──< (N) LibraryEntry ──> (1) Story   // статус: saved | reading | finished
User (N) >──< (N) User             // подписки (follow)
Contest (1) ──< (N) Submission ──> (1) Story
Collection (1) ──< (N) Story       // кураторская связь (модератор)
Notification (N) >── (1) User      // адресат; опц. ссылки на actor / Story / Contest
```

Ключевое различие таксономий: **Genre** — закрытый справочник из 12 категорий, заданный редакцией ([03](03-genre-color-system.md)); **Tag** — открытая UGC-таксономия, теги создают сами авторы, а модератор постфактум переводит их в `accepted` ([11](11-tags.md)).

> Примечание: «Авторлар мектебі» в MVP — статический набор внешних ссылок (см. модуль `LINKS`), отдельных сущностей данных (уроки, модули, инструкторы) не требует.

Ключевые атрибуты сущностей детализированы в модуле [`08-business-rules.md`](08-business-rules.md).
