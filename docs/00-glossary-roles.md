# 00 · Глоссарий, роли и права доступа

## 0.1 Глоссарий предметной области

| Термин (kk / ru) | Определение |
|------------------|-------------|
| **Шығарма** (произведение) | Единица контента верхнего уровня: книга/повесть/рассказ. Содержит метаданные и список глав. |
| **Бөлім** (глава) | Часть произведения. Имеет порядковый номер, заголовок, текст, статус публикации. |
| **Автор** | Пользователь, опубликовавший хотя бы одно произведение или имеющий доступ к авторскому кабинету. |
| **Оқырман** (читатель) | Пользователь, потребляющий контент (чтение, лайки, комментарии, сохранение). |
| **Жанр** | Категория произведения. 12 предустановленных жанров, каждому соответствует цвет (см. модуль 03). |
| **Жинақ** (коллекция) | Кураторская подборка произведений (редакционная). |
| **Конкурс** (байқау) | Литературное состязание с дедлайном, призовым фондом, жюри и правилами подачи. |
| **Авторлар мектебі** (школа авторов) | Образовательный контент (видеолекции, вебинары, интервью, курсы, идеи) на внешних ресурсах. На платформе представлен **блоком ссылок** на эти соцсети/каналы — не отдельной страницей (DEC-02). |
| **Пікір** (комментарий) | Сообщение читателя под произведением/главой. Поддерживает лайки и ответы. |
| **Кітапхана** (библиотека) | Персональное хранилище читателя: сохранённые / читаю сейчас / прочитанные произведения. |
| **Модерация** | Проверка контента перед публикацией согласно правилам платформы. |

## 0.2 Роли пользователей

Платформа различает четыре роли. Роли не взаимоисключающие на уровне человека: один аккаунт может быть одновременно читателем и автором.

### Гость (Guest, не авторизован)
Может просматривать публичный контент, но не взаимодействовать.

### Читатель (Reader, авторизован)
Базовая авторизованная роль. Получается сразу после регистрации.

### Автор (Author)
Читатель, создавший произведение. Получает доступ к авторскому кабинету (модуль `WRITE`). Роль присваивается автоматически при создании первого произведения.

### Модератор / Редактор (Moderator)
Внутренняя роль. Проверяет произведения на модерации, формирует коллекции (жинақтар), курирует «Книгу недели» и редакционные подборки, управляет конкурсами и составом внешних ссылок «Авторлар мектебі».

> ✅ **Решение DEC-01.** Регистрация по умолчанию даёт роль **Читатель**. Роль **Автор** выдаётся не отдельным флагом, а фактом создания первого произведения — отдельной «регистрации автора» не требуется. Это снижает порог входа для UGC-платформы.

## 0.4 Сущности и связи (упрощённая модель данных)

```
User (1) ──< (N) Story
Story (1) ──< (N) Chapter
Story (N) >── (1..2) Genre        // основной + дополнительный жанр
Story (1) ──< (N) Comment
Comment (1) ──< (N) Comment       // ответы (1 уровень вложенности)
User (1) ──< (N) LibraryEntry ──> (1) Story   // статус: saved | reading | finished
User (N) >──< (N) User             // подписки (follow)
Contest (1) ──< (N) Submission ──> (1) Story
Collection (1) ──< (N) Story       // кураторская связь (модератор)
```

> Примечание: «Авторлар мектебі» в MVP — статический набор внешних ссылок (см. модуль `LINKS`), отдельных сущностей данных (уроки, модули, инструкторы) не требует.

Ключевые атрибуты сущностей детализированы в модуле [`08-business-rules.md`](08-business-rules.md).
