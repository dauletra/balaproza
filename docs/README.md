# Документация Qazaqnovel

Qazaqnovel — казахоязычный литературный портал: дети, подростки и молодые взрослые
читают произведения сверстников и публикуют свои.

| Файл | О чём |
|---|---|
| [`architecture.md`](architecture.md) | Продукт, стек, слои, инварианты данных, роли, авторизация |
| [`spec.md`](spec.md) | Требования: FR по модулям, BR, NFR |
| [`ui.md`](ui.md) | Токены, OKLCH-реестры, каркас и навигация, правила компонентов, тон интерфейса |
| [`../README.md`](../README.md) | Установка, ежедневная работа, деплой, чек-лист запуска |

Рабочие заметки для агента — [`../CLAUDE.md`](../CLAUDE.md), это не спецификация.

## Правила работы с документами

1. **Невыполненное помечается ⛔ с объяснением** — иначе документ выглядит описанием
   факта.
2. **Изменение продуктовой логики или интерфейса правит документ тем же коммитом** —
   иначе описание расходится с кодом.

Прежние 21 модуль (00–20) слиты в файлы выше: карта реализации, контракт
тестирования и реестр прошлых решений удалены — их работу делает поиск по коду
и git log.
