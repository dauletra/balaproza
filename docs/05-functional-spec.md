# 05 · Функциональная спецификация

Требования сгруппированы по модулям. Формат: `FR-МОДУЛЬ-NN`. Каждое требование — проверяемое утверждение «система должна…».

---

## 5.1 AUTH · Авторизация

- **FR-AUTH-01.** Вход в систему выполняется через **Telegram** (кнопка «Сайтқа кіру»). Иных способов входа на запуске нет.
- **FR-AUTH-02.** Гость может просматривать публичный контент без входа; интерактивные действия (лайк, комментарий, сохранение, подписка, подача на конкурс) требуют авторизации и вызывают `LoginModal`.
- **FR-AUTH-03.** При первой авторизации пользователь проходит регистрацию (профиль автора), затем онбординг-приветствие (`SignUpSuccess`).
- **FR-AUTH-04.** Форма регистрации содержит поля: **Аты-жөні** (имя, обязательное), **Жынысы** (пол: Ұл/Қыз, радио), **Автор туралы** (биография, TextArea, опционально). Для участия в конкурсах дополнительно фиксируется возраст (BR-20).
- **FR-AUTH-05.** Регистрация завершается только при согласии с правилами и политикой конфиденциальности (чекбокс «Тіркеле отырып … келісесіз»).
- **FR-AUTH-06.** Форма показывает состояния валидации полей в реальном времени (`InputValidated`): success/error с пояснением.
- **FR-AUTH-07.** После входа в шапке отображается аватар + меню профиля и колокольчик уведомлений; для гостя — кнопка «Кіру».

## 5.2 HOME · Главная

> Главная — редакционная витрина, а не плоская лента. (Закрывает находки UX-аудита главной.)

- **FR-HOME-01.** Главная адаптируется под состояние пользователя:
  - **Гость / новый** — приветственный hero + призыв исследовать и стать автором.
  - **Возвращающийся** — блок «Жалғастыру оқу» (продолжить чтение) с последним прогрессом.
- **FR-HOME-02.** Главная содержит **hero-блок конкурса**: обложка, название, отсчёт дней, призовой фонд, кнопка «Қатысу». Не статичный баннер, а действующая карточка (ведёт на детальную конкурса).
- **FR-HOME-03.** Блок **«Апта таңдауы»** (книга недели) — крупная редакционная карточка: обложка, цитата/аннотация от редакции, кнопка «Оқу». Формируется модератором.
- **FR-HOME-04.** Тематические ряды произведений: «Ең көп оқылған», «Жаңа жарияланған», «Жаңа бөлім қосылған». Каждый ряд имеет визуальное отличие (не три идентичных ряда) и ссылку «смотреть все».
- **FR-HOME-05.** Блок **жанров** — цветные `GenreChip` (OKLCH), кликабельны → каталог по жанру.
- **FR-HOME-06.** Блок **коллекций** (жинақтар) — карусель 3–5 кураторских подборок со ссылкой на каталог коллекций.
- **FR-HOME-07.** Блок **новых авторов** — карточки людей (а не только обложки), ведут на профиль.
- **FR-HOME-08.** Emotional-CTA «Стань автором» — приглашение писать (ведёт на создание произведения).
- **FR-HOME-09.** Правый рейл главной несёт продуктовые блоки (автор недели / прогресс чтения / блок ссылок «Авторлар мектебі»). Соцсети как самостоятельный «иди в соцсети»-блок убраны (DEC-18); ссылки школы — это и есть лаконичный блок внешних ресурсов.

## 5.3 CAT · Каталог и поиск

- **FR-CAT-01.** **Поиск** по запросу выдаёт результаты-произведения (`Search results`); поддерживает поиск по названию и автору («Шығарма немесе автор іздеу...»).
- **FR-CAT-02.** Поиск/каталог фильтруется **по жанру** (`Search by genre`).
- **FR-CAT-03.** **Индекс жанров** (`GenreIndex`) — все 12 жанров крупными цветными карточками.
- **FR-CAT-04.** **Коллекции** (`Collections`) — список кураторских подборок; **детальная коллекции** (`CollectionDetail`) — произведения внутри + описание.
- **FR-CAT-05.** Результаты с количеством > одной страницы используют `Pagination`.
- **FR-CAT-06.** **Quick-search popup** (`SearchPopup`) — глобальный модал быстрого поиска. Открытие: хоткей **⌘K / Ctrl+K** или клик по полю/иконке поиска в header. Показывает до 5 произведений и 5 авторов по substring-совпадению. Enter → полная страница `/search/?q=`. Индекс приходит lazy-fetch'ом с `/api/search-index.json` при первом открытии (не нагружает каждый HTML). Доступно всем ролям. (Расширение поверх FR-CAT-01.)
- **FR-CAT-07.** **Сортировка и фильтр** на `SearchResults` и `GenreDetail` (`CatalogControls`):
  - Сортировка: **Танымалдары** (по популярности — views), **Жаңалары** (по дате), **Әліпби бойынша** (по алфавиту title)
  - Фильтр статуса: **Барлығы** / **Жарияланған** / **Аяқталды** / **Жазылып жатыр** (ключи BR-10)
  - Параметры `?sort=&status=`, автосабмит при change, валидация по белому списку.

## 5.4 STORY · Произведение и чтение

- **FR-STORY-01.** Страница произведения содержит шапку: обложка, название, автор (ссылка на профиль), жанр(ы), статистика (лайки/просмотры/комментарии), кнопка «Оқу».
- **FR-STORY-02.** Контент страницы разделён на секции: **Аннотация**, **Бөлімдер** (главы), **Пікірлер** (комментарии). Блок «Басқа шығармалар» (рекомендации) вынесен отдельным блоком внизу.
- **FR-STORY-03.** Навигация по секциям реализована как **sticky scrollspy** (3 пилюли-якоря), а не как табы. Якорь подсвечивается по мере прокрутки (IntersectionObserver). (Закрывает «tabs that don't tab».)

  > ✅ **Решение DEC-15.** Паттерн «декоративные табы, под которыми всё отрендерено сразу» признан анти-паттерном и **исключён**. Везде, где он встречался (Story detail, Profile, mobile), используется либо честное переключение, либо scrollspy-навигация по странице.

- **FR-STORY-04.** Список глав показывает прогресс чтения (напр. «4 / 12 оқылды») и помечает текущую главу.
- **FR-STORY-05.** Секция «Пікірлер» для гостя показывает `CommentLoginGate`; для авторизованного — поле ввода и список комментариев с лайками и ответами.
- **FR-STORY-06.** **Режим чтения** (`Reading`) отображает текст главы с навигацией между главами (пред./след.).
- **FR-STORY-07.** Режим чтения имеет **настройки** в поповере: гарнитура (**Sans** = Open Sans / **Serif** = Georgia), размер шрифта, **тема** (светлая/тёмная).
- **FR-STORY-08.** **Тёмная тема** чтения — отдельное полноценное состояние (`ReadingDark`).
- **FR-STORY-09.** Любой контent можно пожаловать через `ReportModal` (выбор причины + комментарий). Доступно авторизованным.
- **FR-STORY-10.** **Кнопка «Бөлісу»** (`ShareButton`) в шапке произведения. На мобайле (поддержка `navigator.share`) — нативный Web Share API; на десктопе — dropdown с Telegram / WhatsApp / Сілтемені көшіру (clipboard API). Tост-подтверждение копирования через глобальную toast-систему. Доступно всем ролям (шерить можно и анонимно).
- **FR-STORY-11.** Блок «Басқа шығармалар» (см. FR-STORY-02) рендерится через `related_stories(slug)` в `core/stub_data.py`: тот же основной жанр, исключая саму историю и того же автора, только `Published`. При нехватке — добивается популярными `Published` (по views). Лимит по умолчанию — 6, отображение grid 2/3/4/6 колонок (mobile/sm/lg/xl).
- **FR-STORY-12.** **Лайк ставится на главу**, а не на произведение целиком (`ChapterLike`, `components/chapter_like.html`):
  - На уровне данных `Chapter` имеет поля `likes: int` и `liked: bool` (текущий пользователь). Лайк произведения = `sum(c.likes for c in chapters)` — этот агрегат показывается на странице произведения как read-only счётчик с иконкой `heart`.
  - Кнопка лайка появляется **только в режиме чтения** (`Reading`), после текста главы, до навигации к следующей главе. Крупная pill-кнопка с heart-иконкой, счётчиком и подписью «Авторды қолдау — бір рет басу ғана».
  - Гость → клик ведёт на login с `?next=` (FR-AUTH-02). Авторизованный → toggle лайка (heart-filled, brand-error-color), визуальный pulse-эффект, тост «Алғыс үшін рахмет!».
  - В списке глав на `Story detail` (FR-STORY-04) каждая глава показывает свой счётчик лайков — **read-only**; чтобы лайкнуть, надо открыть главу. Это поощряет реальное прочтение.
  - **Обоснование:** литплатформа выигрывает от точечного фидбека («какие главы зацепили, где провал»), а не от единого лайка произведению. Снижает накрутку (нужно открыть главу) и даёт автору карту качества по главам.

## 5.5 WRITE · Авторский кабинет

- **FR-WRITE-01.** **Создание произведения** (`NewStory`): поля — **Атауы** (название), **Аннотация** (TextArea с лимитом), **Жанры** (основной), **Қосымша жанры** (доп., опц.), **Мәртебесі** (статус). Требует согласия с правилами публикации.
- **FR-WRITE-02.** **Мои произведения** (`MyStories`) — список своих работ со статусами (`StatusBadges`) и метриками; пустое состояние (`MyStoriesEmpty`) с призывом создать первое.
- **FR-WRITE-03.** **Управление произведением** (`MyStoryPage`) — обзор глав, статистика, действия (добавить главу, настройки, удалить).
- **FR-WRITE-04.** **Настройки произведения** (`MyStorySettings`) — редактирование метаданных, обложки, жанров, статуса; публикация/снятие с публикации.
- **FR-WRITE-05.** **Редактор главы** (`ChapterEditor`) — заголовок главы + текст, сохранение черновика, публикация главы.
- **FR-WRITE-06.** **Удаление** произведения подтверждается через `DeleteConfirm` (необратимое действие, предупреждение).
- **FR-WRITE-07.** Произведение проходит **модерацию** перед публикацией (статус «Тексеруде» → «Жарияланған»/отклонено) — BR-11.

## 5.6 PROF · Профиль

- **FR-PROF-01.** **Свой профиль** показывает: аватар, имя, биографию, статистику — **Шығарма** (произведений), **Ұнатулар** (лайки), **Оқылды** (прочтения), **Жазылулар** (подписчики).
- **FR-PROF-02.** **Чужой профиль** (`ProfileOther`) — то же + кнопка «Подписаться».
- **FR-PROF-03.** Профиль показывает произведения автора. Навигация по разделам профиля — без анти-паттерна табов (DEC-15); используется сегментированный контрол с реальным переключением (`ProfileSegmented`).
- **FR-PROF-04.** Подписка/отписка на автора (для авторизованных).
- **FR-PROF-05.** **Редактирование своего профиля** (`ProfileMeEdit`, маршрут `/me/edit/`): форма с теми же полями, что и FR-AUTH-04 (Аты-жөні, Жынысы, Жасы, Био). Доступна только авторизованному, кнопка «Профильді өңдеу» в шапке `ProfileMe`. После сохранения — toast и редирект обратно на `/me/`. В дизайне — stub-форма без реальной валидации (заполнится в Ф14).

## 5.7 LIB · Библиотека

- **FR-LIB-01.** Библиотека — личное хранилище читателя с тремя вкладками (`LibraryTabs`): **Сақталған** (сохранённые), **Оқу үстіндегі** (читаю сейчас), **Оқылғаны** (прочитанные).
- **FR-LIB-02.** Произведение попадает в «Оқу үстіндегі» при начале чтения, в «Оқылғаны» — при завершении всех глав, в «Сақталған» — по действию «сохранить».
- **FR-LIB-03.** Из «Оқу үстіндегі» доступно «Жалғастыру» (продолжить с последней главы) — связано с FR-HOME-01.

## 5.8 NOTIF · Уведомления

- **FR-NOTIF-01.** Уведомления сгруппированы по времени: **БҮГІН**, **КЕШЕ**, **ӨТКЕН АПТАДА**.
- **FR-NOTIF-02.** Непрочитанные отражаются счётчиком в шапке и сайдбаре (красный бейдж, DEC-07).
- **FR-NOTIF-03.** Типы событий: новый комментарий, лайк, новая глава у отслеживаемого произведения, новый подписчик, результат модерации, статус заявки на конкурс.
- **FR-NOTIF-04.** Пустое состояние (`NotificationEmpty`) с поясняющим текстом.

## 5.9 CONT · Конкурсы

> Раздел добавлен как полноценные страницы. (Закрывает находку UX-аудита конкурсов: «страницы конкурсов не существует».)

- **FR-CONT-01.** **Список конкурсов** (`ContestList`): карточки активных и завершённых. Карточка содержит обложку, название, подзаголовок (категория), статус, для активных — отсчёт дней, призовой фонд, число поданных работ.
- **FR-CONT-02.** Статусы конкурса: **active** (идёт) и **finished** (завершён) — BR-40.
- **FR-CONT-03.** **Детальная конкурса** (`ContestDetail`): описание, условия, **таймлайн** (этапы), **отсчёт** до дедлайна, **жюри** (`ContestJury` — имя + роль), призовой фонд, кнопка «Қатысу».
- **FR-CONT-04.** **Подача работы** (`ContestSubmit`): автор выбирает одно из своих произведений; система показывает чек-лист соответствия требованиям (объём, язык, оригинальность, AI-декларация, возраст) — BR-22.
- **FR-CONT-05.** Подача требует авторизации; правило **«один автор — одна работа»** на конкурс (BR-23).
- **FR-CONT-06.** **Мои заявки** (`MySubmissions`): список поданных работ со статусом — **reviewing** (на рассмотрении), **accepted** (принята), и др. (BR-41).
- **FR-CONT-07.** Произведения, не прошедшие порог объёма (5 000–15 000 знаков), к подаче недоступны с пояснением причины.

## 5.10 LINKS · «Авторлар мектебі» — блок внешних ссылок

> На первой версии (MVP) образовательный контент не размещается на платформе. «Авторлар мектебі» — это блок ссылок на внешние ресурсы, где живут видеолекции, вебинары, интервью, курсы и идеи (DEC-02). Это возврат к изначальной задумке дизайна ради упрощения запуска.

- **FR-LINKS-01.** Блок «Авторлар мектебі» представляет собой список ссылок на внешние ресурсы (соцсети/каналы), сгруппированных по типу контента.
- **FR-LINKS-02.** Каждая ссылка содержит: иконку канала, название, краткую подпись о содержимом. Примерный состав (управляется модератором):
  | Канал | Подпись (тип контента) |
  |-------|------------------------|
  | YouTube | Вебинарлар мен курстар (вебинары и курсы) |
  | Instagram | Интервью, сұрақ-жауап (интервью, Q&A) |
  | TikTok | Пайдалы кеңес, идеялар (полезные советы, идеи) |
  | Telegram | Ең қызық шығармалар / жаңалықтар (анонсы) |
- **FR-LINKS-03.** Все ссылки открываются во внешней вкладке (`target="_blank"`, `rel="noopener noreferrer"`); внутри платформы видео/контент **не** встраивается и **не** воспроизводится.
- **FR-LINKS-04.** Блок доступен всем ролям, включая гостя (это просто ссылки, авторизация не нужна).
- **FR-LINKS-05.** Точки размещения блока: **footer** (как пункт «Авторлар мектебі») и при необходимости — компактный блок в правом рейле/на главной. Отдельной страницы-маршрута для школы нет.
- **FR-LINKS-06.** Набор ссылок — конфигурируемые данные (не зашит в разметку), редактируется без переката кода (NFR-52).

> ✅ **Решение DEC-22.** Внутренняя страница школы с уроками, модулями, инструкторами и прогрессом (`SchoolHero`, `SchoolLessonGrid`, `LessonCard`, `SchoolInstructors`, `SchoolModuleNav`) **исключена из MVP**. Соответствующие FR-SCHOOL-01…07 и бизнес-правила BR-50…53 аннулированы. Вместо них — модуль LINKS.

## 5.11 LEGAL · Правовые и информационные стабы

- **FR-LEGAL-01.** Сайт содержит 5 статичных страниц с правовой/проектной информацией, на которые ведут ссылки из footer (`docs/07.5`):
  | Маршрут | Заголовок (kk) | Назначение |
  |---------|---------------|------------|
  | `/rules/moderation/` | Модерация ережелері | Что и почему модерируется |
  | `/rules/publishing/` | Жариялау шарттары | Условия публикации, авторские права |
  | `/about/` | Проект туралы | О проекте Balaproza |
  | `/terms/` | Пайдалану ережелері | Terms of Service |
  | `/privacy/` | Құпиялылық саясаты | Privacy Policy |
- **FR-LEGAL-02.** Все 5 страниц используют единый шаблон `pages/legal.html` (заголовок, подзаголовок, контент, дата последнего обновления). Контент в MVP — stub-плейсхолдер; финальный текст готовит контент-менеджер.
- **FR-LEGAL-03.** Доступ — публичный для всех ролей (включая гостя).
- **FR-LEGAL-04.** Чекбокс согласия при регистрации (FR-AUTH-05) ссылается минимум на `legal_terms` и `legal_privacy`.

## 5.12 SYS · Системные

- **FR-SYS-01.** **Toast-уведомления** трёх типов (success/info/error), автоскрытие, неблокирующие. Глобальный приёмник `toast_host.html` подключён в `base.html`; страница диспатчит `$dispatch('toast', {kind, text})`.
- **FR-SYS-02.** Все деструктивные действия подтверждаются модалкой.
- **FR-SYS-03.** Единые компоненты пагинации, бейджей, аватаров используются во всех модулях (без локальных дублей).
