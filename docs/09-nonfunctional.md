# 09 · Нефункциональные требования

Формат: `NFR-NN`.

## 9.1 Доступность (Accessibility)

В прототипе доступность заложена в `styles.css` (фокус-стили, sr-only, aria-метки) — в ТЗ это становится обязательным минимумом.

- **NFR-01.** Все интерактивные элементы имеют видимое состояние `:focus-visible` (обводка `2px solid --teal`, offset 2px) для клавиатурной навигации.
- **NFR-02.** Иконки-кнопки имеют `aria-label` (напр. «Жабу», «Сақтау», «Оқу баптаулары», «Хабарламалар (3 оқылмаған)»).
- **NFR-03.** Навигация размечена семантически (`<nav aria-label="Негізгі мәзір">`); используется `.sr-only` для скрытого вспомогательного текста.
- **NFR-04.** Контраст текста к фону соответствует WCAG AA. Для жанровых цветов контраст гарантирован моделью OKLCH (фиксированные L/C — модуль 03).
- **NFR-05.** Модалки реализуют focus-trap, закрытие по `Esc`, возврат фокуса на триггер после закрытия.
- **NFR-06.** Формы: лейблы связаны с полями; ошибки — через `aria-describedby` (DEC-13).
- **NFR-07.** Целевая аудитория — дети: интерфейс на казахском, простые формулировки, крупные тач-зоны (мин. 44×44px на мобайле).

## 9.2 Производительность

- **NFR-10.** Целевой First Contentful Paint < 2с на среднем мобильном соединении.
- **NFR-11.** Шрифты — self-hosted (DEC-04), с `font-display: swap`.
- **NFR-12.** Изображения обложек — оптимизированные форматы (WebP/AVIF) с фиксированными размерами слотов (предотвращение layout shift, CLS≈0).
- **NFR-13.** Списки с пагинацией не грузят всё разом; длинные списки — пагинация или ленивая подгрузка.
- **NFR-14.** Прод-сборка вместо Babel-in-browser (DEC-04): tree-shaking, code-splitting по маршрутам.

## 9.3 Безопасность и приватность (детская платформа)

- **NFR-20.** Платформа ориентирована на несовершеннолетних — повышенные требования к безопасности контента.
- **NFR-21.** Весь UGC проходит модерацию перед публичной публикацией (BR-11).
- **NFR-22.** Механизм жалоб (`ReportModal`) доступен на всём пользовательском контенте (BR-33).
- **NFR-23.** Личные сообщения между пользователями на запуске отсутствуют (снижение рисков груминга).
- **NFR-24.** Минимизация персональных данных: хранится необходимый минимум; согласие с политикой конфиденциальности обязательно при регистрации (FR-AUTH-05).
- **NFR-25.** Вход через Telegram — проверка подлинности на стороне сервера (валидация подписи Telegram Login Widget), а не доверие клиенту.
- **NFR-26.** AI-декларация в конкурсах (DEC-21) — для прозрачности авторства детских работ.

## 9.4 Локализация

- **NFR-30.** Основной язык интерфейса — **казахский**. Все строки UI вынесены в ресурсы локализации (без хардкода в компонентах).
- **NFR-31.** Контент (произведения) — казахский и русский (BR-21).
- **NFR-32.** Числа/даты/валюта форматируются по локали (валюта — ₸, тенге).

## 9.5 Совместимость

- **NFR-40.** Поддержка современных браузеров (последние 2 версии Chrome, Safari, Firefox, Edge).
- **NFR-41.** OKLCH-цвета с sRGB-fallback для старых движков (DEC-12).
- **NFR-42.** Адаптивность: 375px (mobile) → 768px (tablet) → 1440px (desktop); резиновая сетка между брейкпоинтами (DEC-03).

## 9.6 Поддерживаемость

- **NFR-50.** Дизайн-токены — единый источник правды (CSS-переменные); прямые цвета в компонентах запрещены (DEC-05).
- **NFR-51.** Компоненты переиспользуемы, без локальных копий (единые Badge, Pagination, Avatar, GenreChip — DEC-14).
- **NFR-52.** Справочники (жанры, статусы конкурсов, набор внешних ссылок «Авторлар мектебі») — конфигурируемые данные, не зашиты в разметку.
- **NFR-53.** Артефакты ревью (`design-canvas.jsx`, `_review/`, `.design-canvas.state.json`) не входят в продакшен-сборку.

## 9.7 Production readiness

- **NFR-60.** **Branded error pages** обязательны (FR-SYS-04):
  - `templates/404.html` — extends `base.html`, содержит логотип, заголовок «Бет табылмады», кнопки «Басты бет» / «Жанрлар» / «Іздеу ашу».
  - `templates/500.html` — **standalone** (без `extends base.html` и без `context_processors`), чтобы не падать каскадом при server error. Минимальный HTML, тот же favicon и theme-color, кнопки «Басты бетке» / «Қайталау».
- **NFR-61.** **Favicon и theme-color** подключены в `base.html` (`<link rel="icon">`, `<link rel="apple-touch-icon">`, `<meta name="theme-color" content="#036672">`). До подготовки оптимизированной иконки — используется `static/img/logo.png`. **TODO для продакшена:** заменить на `.ico` или `.svg`, добавить полный favicon-set (16/32/192/512 + maskable).
- **NFR-62.** **OG-метаданные и SEO** — на MVP не подключены сознательно (только favicon + theme-color). К официальному запуску **обязательно**: `og:title`, `og:description`, `og:image` (с динамическим генератором карточек на основе обложки произведения), `meta description`, `meta keywords`, structured data (schema.org/Article или Book).
- **NFR-63.** **Sitemap.xml и robots.txt** — на MVP отсутствуют. К официальному запуску добавить через `django.contrib.sitemaps` + view для `/robots.txt`.
- **NFR-64.** **Правовые стабы** (FR-LEGAL) обязательны до запуска: 5 маршрутов с минимальным контентом. Без них footer-ссылки ведут в пустоту, что нарушает FR-AUTH-05 (согласие при регистрации) и юридические требования.
- **NFR-65.** **HTTPS-only** в production: `SECURE_SSL_REDIRECT=True`, `SECURE_HSTS_SECONDS≥31536000`, `SESSION_COOKIE_SECURE=True`, `CSRF_COOKIE_SECURE=True`. Особенно критично для детской платформы.
