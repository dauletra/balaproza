# 02 · Дизайн-система

Единый источник правды для всех визуальных решений. Все токены обязательны к использованию через CSS-переменные; прямые `rgb(...)` в компонентах запрещены (DEC-05).

## 2.1 Цветовые токены

### Бренд

| Токен | HEX / значение | Применение |
|-------|----------------|-----------|
| `--teal` | `rgb(3,102,114)` | **Основной бренд и цвет действия.** Primary-кнопки, активная навигация, ссылки, фокус-обводка |
| `--teal-dark` | `rgb(5,80,92)` | Hover/active основной кнопки |
| `--teal-light` | `rgba(3,102,114,0.42)` | Полупрозрачные акценты |

> ✅ **Решение DEC-06.** В прототипе встречались **два** цвета действия: бирюзовый `rgb(3,102,114)` (десктоп) и синий `rgb(26,86,219)` (центральная кнопка mobile-навигации, бейджи). Фиксируется **единый accent — бирюзовый `--teal`**. Синий перестаёт быть «вторым primary»: центральная кнопка «создать» в mobile-навигации перекрашивается в `--teal`. Синий сохраняется только как **информационный семантический цвет** (статус «Аяқталды», info-бейджи) — см. ниже.

|-----------|-------|-----|-----------|

| Информация / завершено | `rgb(26,86,219)` | `rgb(225,239,254)` | Статус «Аяқталды», info-бейджи |

### Акцентный токен промо-конкурса

| Токен | Значение | Применение |
|-------|----------|-----------|
| `--promo-bg` | `rgb(227,255,134)` (жёлто-зелёный) | Фон промо-баннера конкурса |
| `--promo-cta` | `rgb(158,34,34)` (тёмно-красный) | Кнопка «Толығырақ/Қатысу» на баннере |

> ✅ **Решение DEC-08.** Ярко-контрастная пара жёлто-зелёный + красный выходит за пределы основной палитры **намеренно** — это сигнальный акцент для конкурсов (главный канал привлечения авторов). Фиксируется как отдельный токен-набор `--promo-*`, применяется **только** к промо-блокам конкурсов, нигде больше.

## 2.5 Сетка отступов

Базовая единица — **4px**. Типовые шаги: 4 / 8 / 12 / 16 / 18 / 24. Вертикальный ритм карточных рядов — 16px между карточками, 16px заголовок→ряд.

## 2.6 Состояния интерактивных элементов (обязательны)

Каждый интерактивный компонент реализует пять состояний:

1. **Default** — базовый вид.
2. **Hover** — для primary-кнопки фон `--teal-dark`; для карточки `transform: translateY(-2px)` + тень.
3. **Focus-visible** — обводка `2px solid --teal`, `outline-offset: 2px` (только для клавиатурной навигации).
4. **Active/pressed** — затемнение/смещение.
5. **Disabled** — пониженная непрозрачность, `cursor: not-allowed`, действия заблокированы.

> ✅ **Решение DEC-10.** Disabled-состояние в прототипе не было проработано системно — фиксируется как обязательное для всех кнопок и полей.
