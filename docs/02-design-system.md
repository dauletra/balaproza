# 02 · Дизайн-система

> `Обновлён: 2026-08-20` · `Сверен с кодом: 5d39adb`

Единый источник правды для всех визуальных решений. Все токены обязательны к использованию через CSS-переменные; прямые `rgb(...)` в компонентах запрещены (DEC-05).

> **Где живут токены.** Все токены объявлены в блоке `@theme` внутри [`static_src/input.css`](../static_src/input.css) — это Tailwind CSS v4, `tailwind.config.js` не используется (DEC-29). Имена цветовых токенов **обязаны** начинаться с `--color-`, иначе Tailwind не породит из них утилиты (`bg-brand`, `text-slate-600`). Ниже приведены фактические имена из `@theme`; utility-класс образуется отбрасыванием префикса `--color-` / `--radius-` / `--shadow-`.

## 2.1 Цветовые токены

### Бренд

| Токен | Значение | Utility | Применение |
|-------|----------|---------|-----------|
| `--color-brand` | `rgb(3,102,114)` | `bg-brand`, `text-brand` | **Основной бренд и цвет действия.** Primary-кнопки, активная навигация, ссылки, фокус-обводка |
| `--color-brand-dark` | `rgb(5,80,92)` | `bg-brand-dark` | Hover/active основной кнопки |
| `--color-brand-light` | `rgba(3,102,114,0.42)` | `bg-brand-light` | Полупрозрачные акценты |

> ✅ **Решение DEC-06.** В прототипе встречались **два** цвета действия: бирюзовый `rgb(3,102,114)` (десктоп) и синий `rgb(26,86,219)` (центральная кнопка mobile-навигации, бейджи). Фиксируется **единый accent — бирюзовый `--color-brand`**. Синий перестаёт быть «вторым primary»: центральная кнопка mobile-навигации перекрашена в brand. Синий сохраняется только как **информационный семантический цвет** (статус «Аяқталды», info-бейджи) — см. ниже.

## 2.2 Типографика

| Шрифт | Роль | Начертания |
|-------|------|-----------|
| **Montserrat** | Заголовки, бренд-логотип, заголовки секций, метки кнопок | 400/500/600/700/800 |
| **Open Sans** | Основной текст интерфейса, карточки, формы (доминирующий) | 400/600/700 |
| **Inter** | Точечные интерактивные акценты (напр. «жауап беру») | 400/500/800 |

Все три — self-hosted variable WOFF2 в `static/fonts/` (`font-weight: 100 900`, `font-display: swap`), italic-начертания подгружаются отдельными файлами. Токены: `--font-display`, `--font-sans`, `--font-ui`.

> ✅ **Решение DEC-09a.** Caveat (рукописный) из прототипа в продакшен **не переносится** — он применялся только в декоре канваса ревью. Продуктовых шрифтов три: Montserrat, Open Sans, Inter.

> ✅ **Закрыто решением DEC-35 (бывший Q-10).** Гарнитура в режиме чтения — та же `Open Sans`, что и в остальном интерфейсе. Токен --font-serif (Georgia) удалён: он три месяца стоял в `@theme` и в showcase токенов, не применяясь ни на одном экране продукта. Переключателя Sans/Serif нет; третья ось настроек чтения — межстрочный интервал (FR-STORY-07). Редактор главы, который прежде обещал автору «Georgia, ұзын жолдар» и набирал textarea шрифтом Georgia, переведён на ту же гарнитуру и тот же кегль, что видит читатель.

| `--radius-sm` | `4px` | `rounded-sm` | Мелкие блоки, скелетоны |
| `--radius-chip` | `6px` | `rounded-chip` | Мелкие чипы, бейджи на обложке |
| `--radius-md` | `8px` | `rounded-md` | **Базовый**: кнопки, поля ввода, обложки книг |
| `--radius-lg` | `12px` | `rounded-lg` | Карточки и крупные блоки |

### Размеры каркаса

> ✅ **Актуализировано по DEC-25.** Левый sidebar исключён, контейнер сужен с 1440 до 1280, правый рейл расширен с 234 до 300px. Прежние величины (сайдбар 189px, отступ контента 325px, контентная колонка 737px) больше не применяются.

| Параметр | Значение |
|----------|----------|
| Ширина контентного контейнера | `max-w-[1280px]`, центрирован |
| Ширина колонки контента | `max-w-[860px]` на `<main>`, `mx-auto` — одинакова с рейлом и без него (07 §7.1) |
| Боковые поля контейнера | `px-4` → `sm:px-6` → `lg:px-12` |
| Высота шапки | 64px (`sticky top-0`) |
| Правый рейл | 300px, `shrink-0`, виден **только с `xl`** и только при `has_right_rail=True` |
| Зазор контент ↔ рейл | 24px (`gap-6`) |
| Mobile bottom-nav | 360×64, плавающая пилюля, `bottom-4`, скрыта с `md` |
| Нижний отступ контента | `pb-24` на mobile (место под nav) → `md:pb-12` |
| Опорная ширина mobile-макета | 375px |

## 2.5 Сетка отступов

Базовая единица — **4px**. Типовые шаги: 4 / 8 / 12 / 16 / 18 / 24. Вертикальный ритм карточных рядов — 16px между карточками, 16px заголовок→ряд.

## 2.6 Состояния интерактивных элементов (обязательны)

Каждый интерактивный компонент реализует пять состояний:

1. **Default** — базовый вид.
2. **Hover** — для primary-кнопки фон `--color-brand-dark`; для карточки `transform: translateY(-2px)` + тень.
3. **Focus-visible** — обводка `2px solid --color-brand`, `outline-offset: 2px`, `border-radius: 4px` (только для клавиатурной навигации). Задано глобально в `@layer base` внутри `input.css`, поэтому действует на всём без разметки в компонентах.
4. **Active/pressed** — затемнение/смещение.
5. **Disabled** — пониженная непрозрачность, `cursor: not-allowed`, действия заблокированы.

> ✅ **Решение DEC-10.** Disabled-состояние в прототипе не было проработано системно — фиксируется как обязательное для всех кнопок и полей.
