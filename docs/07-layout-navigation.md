# 07 · Каркас и навигация

## 7.1 Десктопный каркас `DesktopShell`

Постоянная рамка, наполняемая контентом. Меняется только контентная область и правый рейл.

```
┌──────────────────────────────────────────────────────────┐
│ DesktopHeader  64px                                        │
│ [Logo]   [🔍 Шығарма немесе автор іздеу...]   [CTA][🔔][👤]│
├────────┬─────────────────────────────────┬────────────────┤
│Sidebar │ Контент (left:325)              │ RightRail      │
│189px   │                                 │ (сменный)      │
│Басты б.│                                 │                │
│Кітапх. │                                 │                │
│Жазу    │                                 │                │
│Хабарл.③│                                 │                │
│Профиль │                                 │                │
├────────┴─────────────────────────────────┴────────────────┤
│ DesktopFooter — контакты, ссылки, соцсети, ТАРАЗ 2024      │
└────────────────────────────────────────────────────────────┘
```

**Параметры `DesktopShell`:** `active` (активный пункт меню), `signedIn`, `ctaLabel` (по умолч. «Шығарма жазу»), `rightRail` (сменный блок), `withSidebar`, `withFooter`.

## 7.2 Шапка `DesktopHeader`

| Элемент | Спецификация |
|---------|--------------|
| Логотип | left:125, кликабелен → главная |
| Поиск | 520×35, radius 24, фон `--slate-100`, плейсхолдер «Шығарма немесе автор іздеу...» |
| CTA | «Шығарма жазу», текст `--teal`, ведёт на создание произведения |
| Уведомления | колокольчик + красный счётчик непрочитанных; `aria-label` с числом |
| Профиль | аватар 36 + стрелка-меню (для авторизованного) |
| Гость | вместо профиля — кнопка «Кіру» |

## 7.3 Левый сайдбар `DesktopSidebar`

Семантический `<nav aria-label="Негізгі мәзір">`, ширина 189px.

Набор зависит от статуса аутентификации:

**Гость:** home · catalog (Жанрлар) · contests.

**Авторизованный:**

| key | Лейбл | Иконка | Особенность |
|-----|-------|--------|-------------|
| home | Басты бет | Home | — |
| library | Кітапхана | Book | — |
| write | Жазу | Pen | — |
| contests | Конкурстар | Adjustments | связан с авторским флоу (FR-CONT) |
| notifications | Хабарламалар | Bell | красный бейдж-счётчик |
| profile | Профиль | UserCircle | — |

Активный пункт — цвет `--teal`, начертание 700. Неактивные — `--slate-900`, 400.

## 7.4 Правый рейл (сменный)

> ✅ **Решение DEC-18.** Правый рейл **не содержит соцсети** (закрывает UX-аудит «Right rail»: соцсети как костыль контент-стратегии). Соцсети переносятся в footer. Правый рейл несёт продуктовые блоки в зависимости от контекста страницы:

| Контекст | Содержимое рейла |
|----------|------------------|
| Главная | Автор недели / прогресс чтения / блок ссылок «Авторлар мектебі» |
| Страница произведения | Карточка автора + список глав |
| Чтение | Список глав (навигация) |
| Авторский кабинет | Статистика писателя |

## 7.5 Footer `DesktopFooter`

Фон `--slate-100`, поля 125px. Три колонки:

1. **БАЙЛАНЫС** — email (daulet.rakhmankul@gmail.com), иконки соцсетей (YouTube, Instagram, TikTok, Telegram).
2. **Ссылки** — Модерация ережелері, Жариялау шарттары, **блок «Авторлар мектебі»** (заголовок-секция + inline-список внешних ссылок, рендерится через `components/school_links.html` с `layout="inline"`). Отдельного маршрута/страницы нет (DEC-22), заголовок не кликабельный.
3. **Ссылки** — Проект туралы, Пайдалану ережелері, Құпиялылық саясаты.

Низ: разделитель + копирайт «ТАРАЗ 2024» по центру.

> ✅ **Решение DEC-19 (ред. для MVP).** Соцсети размещаются в footer и в блоке «Авторлар мектебі». Весь образовательный контент (видеолекции, вебинары, интервью, курсы) живёт **на внешних каналах** и смотрится вне платформы — встраивание видео на сайт в MVP не делается (DEC-02/DEC-22). Instagram/TikTok/Telegram/YouTube — каналы дистрибуции, на которые ведут ссылки.

## 7.6 Мобильная навигация

### `MobileHeader` (375×64)
Логотип + иконка поиска. Нижняя граница `--slate-300`.

### `MobileBottomNav` (плавающая пилюля 360×64, radius 999)

Набор зависит от роли:

**Гость:**
```
[ Home ] [ Genres ] [ ⊕ (Login) ] [ Contests ] [ Search ]
```

**Авторизованный:**
```
[ Home ] [ Contests ] [ ⊕ (NewStory) ] [ Bell ] [ Profile ]
```

- Центральная кнопка-FAB — круг `--teal` с белым `Plus` (DEC-06: бирюзовый, не синий). У гостя ведёт на login, у авторизованного — на создание нового произведения.
- Активный пункт — `--teal`; неактивные — `--slate-800`.
- Тень `0 4px 14px rgba(0,0,0,0.06)`.
- **Library и my_submissions** у авторизованного **не** входят в bottom nav (5 слотов — оптимальный лимит UX-привычки). Они доступны через dropdown header (desktop) и `core:contest_list` → «Менің өтінімдерім».

## 7.7 Жанровая полоса

`DesktopGenreStrip` / mobile-аналог. Метка «ЖАНРЛАР» + цветные `GenreChip` топ-жанров + пункт «БАРЛЫҚ ЖАНР». Клик по чипу → каталог по жанру.

> ✅ **Решение DEC-20.** Плоская текстовая полоса жанров заменена цветными чипами OKLCH (DEC-11/DEC-14), что закрывает находку UX-аудита: «жанры должны выглядеть как приглашение, а не меню фильтров».

## 7.8 Якорная навигация на длинных страницах

Страница произведения и профиль используют **sticky scrollspy** (пилюли-якоря с подсветкой активной секции через IntersectionObserver) вместо декоративных табов (DEC-15).
