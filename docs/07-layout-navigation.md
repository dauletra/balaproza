# 07 · Каркас и навигация

## 7.1 Десктопный каркас `DesktopShell`

Постоянная рамка, наполняемая контентом. Левый sidebar исключён (DEC-25). В хедере остаются два главных продуктовых входа: «Оқу» (`/catalog/`) для чтения и «Байқаулар» для конкурсов. Footer работает как карта сайта. Меняется только контентная область и правый рейл (опционально).

```
┌────────────────────────────────────────────────────────────┐
│ DesktopHeader  64px                                         │
│ [Logo]  [🔍 Шығарма немесе автор іздеу...]  [Байқаулар]     │
│         [✎ Шығарма жазу]  [🔔]  [👤▾]   /   [Кіру]          │
├──────────────────────────────────────────┬─────────────────┤
│ Контент (full-width до max-w-1280)        │ RightRail       │
│                                           │ 300px (опц.)    │
│                                           │                 │
├──────────────────────────────────────────┴─────────────────┤
│ DesktopFooter — карта сайта (Контент / Сайт / Құжаттар) +   │
│ соцсети + ТАРАЗ 2024                                        │
└────────────────────────────────────────────────────────────┘
```

**Параметры:** `has_right_rail` (bool, страница передаёт через context). При `False` правый `<aside>` не рендерится — контент тянется на всю ширину контейнера. Контейнер: `max-w-[1280px]`, padding `lg:px-12`.

## 7.2 Шапка `DesktopHeader`

Однострочная, h=64px. Состав слева направо:

| Элемент | Спецификация |
|---------|--------------|
| Логотип | кликабелен → главная |
| Поиск | 520×35, radius 24, фон `--slate-100`, плейсхолдер «Шығарма немесе автор іздеу...». Клик/фокус → открывает Cmd+K popup |
| Байқаулар | единственная контентная ссылка в нав-кластере (DEC-25). Активный стейт — `text-brand`, иначе `text-slate-700 hover:text-brand` |
| CTA «Шығарма жазу» | иконка pen + текст, `--teal` |
| Уведомления (auth) | колокольчик + красный счётчик непрочитанных; `aria-label` с числом |
| Профиль (auth) | аватар 36 + chevron → dropdown (Профиль / Менің шығармаларым / Кітапхана / Менің заявкаларым / Шығу). Каждый пункт с slim-иконкой слева |

Mobile bottom nav:
- Гость: home / catalog / login (FAB) / contests / search.
- Авторизованный: home / library / new_story (FAB) / contests / profile.
| Кіру (гость) | вместо аватара — текстовая ссылка `text-brand` |

## 7.3 Левый сайдбар (исключён — DEC-25)

На десктопе левый sidebar отсутствует. Главный вход в чтение — «Оқу» в header (`/catalog/`). Жанры остаются обзорной страницей и секцией главной, а Жинақтар — отдельным editorial-разделом в footer. Конкурсы — отдельная ссылка в хедере.

На mobile навигация — bottom_nav (5 кнопок, см. 7.6), без изменений.

## 7.4 Правый рейл (сменный)

> ✅ **Решение DEC-18.** Правый рейл **не содержит соцсети** (закрывает UX-аудит «Right rail»: соцсети как костыль контент-стратегии). Соцсети переносятся в footer. Правый рейл несёт продуктовые блоки в зависимости от контекста страницы:

| Контекст | Содержимое рейла |
|----------|------------------|
| Главная | Блок ссылок «Авторлар мектебі» (continue-reading и contest переехали в hero / banner) |
| Каталог (search/genre/tag/catalog, DEC-27) | `_filter_panel` — sort, status, search refining, genre chip-cloud, popular tags. Та же панель открывается на mobile через bottom-sheet по `open-catalog-filters` |
| Страница произведения | Карточка автора + список глав |
| Чтение | Список глав (навигация) |
| Авторский кабинет | Статистика писателя |

> ✅ **Решение DEC-27 (выдержка).** На каталог-страницах рейл становится фильтр-панелью. На mobile та же панель доступна через bottom-sheet (партиал `_filter_sheet`, триггер — кнопка «Сүзгілер» в основном контенте, событие `open-catalog-filters`). Контейнер рейла расширен с 234px до 300px ради осмысленных виджетов.

## 7.5 Footer `DesktopFooter`

После DEC-25 footer служит «картой сайта» — здесь живут все контентные разделы, не помещённые в навигацию хедера. Фон `--slate-100`, padding `lg:px-12`. Четыре колонки на lg+, 2 на sm-md, стек на mobile:

1. **Байланыс** — email + иконки соцсетей (YouTube, Instagram, TikTok, Telegram).
2. **Контент** — Жанрлар · Жинақтар · Байқаулар.
3. **Сайт** — Проект туралы · Жариялау шарттары · Модерация ережелері.
4. **Құжаттар + Авторлар мектебі** — Пайдалану ережелері · Құпиялылық саясаты + inline-блок 4 внешних ссылок школы (рендерится через `components/school_links.html` с `layout="inline"`).

Низ: разделитель + копирайт «ТАРАЗ 2024» по центру.

> ✅ **Решение DEC-19 (ред. для MVP).** Соцсети размещаются в footer и в блоке «Авторлар мектебі». Весь образовательный контент (видеолекции, вебинары, интервью, курсы) живёт **на внешних каналах** и смотрится вне платформы — встраивание видео на сайт в MVP не делается (DEC-02/DEC-22). Instagram/TikTok/Telegram/YouTube — каналы дистрибуции, на которые ведут ссылки.

## 7.6 Мобильная навигация

### `MobileHeader` (375×64)
Логотип + иконка поиска. Нижняя граница `--slate-300`.

### `MobileBottomNav` (плавающая пилюля 360×64, radius 999)

Набор зависит от роли:

**Гость:**
```
[ Home ] [ Catalog ] [ ⊕ (Login) ] [ Contests ] [ Search ]
```

**Авторизованный:**
```
[ Home ] [ Library ] [ ⊕ (NewStory) ] [ Contests ] [ Profile ]
```

- Центральная кнопка-FAB — круг `--teal` с белым `Plus` (DEC-06: бирюзовый, не синий). У гостя ведёт на login, у авторизованного — на создание нового произведения.
- Активный пункт — `--teal`; неактивные — `--slate-800`.
- Тень `0 4px 14px rgba(0,0,0,0.06)`.
- **Library** у авторизованного входит в bottom nav как главный возврат к чтению. `my_submissions` не входит в 5 слотов и остаётся доступен через профиль/contest flow.

## 7.7 Жанровая полоса

`DesktopGenreStrip` / mobile-аналог. Метка «ЖАНРЛАР» + цветные `GenreChip` топ-жанров + пункт «БАРЛЫҚ ЖАНР». Клик по чипу → каталог по жанру.

> ✅ **Решение DEC-20.** Плоская текстовая полоса жанров заменена цветными чипами OKLCH (DEC-11/DEC-14), что закрывает находку UX-аудита: «жанры должны выглядеть как приглашение, а не меню фильтров».

## 7.8 Якорная навигация на длинных страницах

Страница произведения и профиль используют **sticky scrollspy** (пилюли-якоря с подсветкой активной секции через IntersectionObserver) вместо декоративных табов (DEC-15).
