# 03 · Система жанровых цветов (OKLCH)

> `Обновлён: 2026-08-21` · `Сверен с кодом: f1f896b`

Жанровый цвет — навигационный инструмент: помогает мгновенно опознавать жанр в каталоге, на карточках и в чипах. Реализуется как детерминированная функция от тона (hue) в пространстве OKLCH.

## 3.1 Принцип

Светлота (L) и насыщенность (C) **фиксированы** для всех жанров; меняется только **hue (H)**. Это даёт визуально гармоничный набор и — главное — **гарантированный, одинаковый контраст** текста к фону для каждого жанра без ручной проверки пар.

## 3.3 Реестр ролей

Базовая тройка, из которой выросла система:

| Роль | Формула OKLCH | Назначение |
|------|---------------|-----------|
| `bg` | `oklch(0.96 0.04 H)` | Фон чипа/карточки — почти белый с оттенком |
| `fg` | `oklch(0.38 0.14 H)` | Текст/иконка — тёмный, насыщенный |
| `ring` | `oklch(0.86 0.08 H)` | Граница/обводка |

Жанр вне справочника → нейтральный fallback: `bg rgb(243,244,246)`, `fg rgb(75,85,99)`, `ring rgb(229,231,235)`.

### Полный реестр (фактический)

По ходу верстки ролей стало больше трёх: типографическая обложка, аватар, карточки коллекций и книга недели используют собственные ступени светлоты. Ниже — **все** пары `L C`, встречающиеся в шаблонах. Новые значения без внесения в эту таблицу добавлять нельзя (NFR-50).

| `L C` | Роль | Где применяется |
|-------|------|-----------------|
| `0.96 0.04` | `bg` — фон чипа/тайла | `genre_chip`, `genre_index`, `_hero_genre` |
| `0.86 0.08` | `ring` — граница | `genre_chip`, `genre_index`, `_hero_genre`, `avatar`, `collections` |
| `0.38 0.14` | `fg` — текст чипа | `genre_chip`, `genre_index`, `_hero_genre` |
| `0.55 0.14` | `dot` — точка-маркер перед названием жанра | `genre_chip`, `genre_strip`, `_filter_panel` |
| `0.32 0.14` | `ink` — крупная типографика на светлой плашке | `avatar` (инициалы), `cover_placeholder` (буква), `book_of_week`, `_filter_panel` |
| `0.90 0.06` | `plate` — фон типографической обложки | `cover_placeholder` |
| `0.92 0.06` | фон градиента карточки | `book_of_week` |
| `0.50 0.14` | акцент карточки | `book_of_week` |
| `0.95 0.05` | фон карточки коллекции | `collections` |
| `0.86 0.07` | граница карточки коллекции | `collections` |
| `0.48 0.14` | иконка коллекции (с `opacity: 0.6`) | `collections` |
| `0.28 0.14` | заголовок коллекции | `collections`, `collection_detail` |
| `0.26 0.12` | текст коллекции | `collections` |
| `0.42 0.10` | вторичный текст коллекции | `collections` |
| `0.97 0.03` | фон hero коллекции | `collection_detail` |

> **Hue берётся из двух источников.** У жанровых поверхностей — `Genre.hue` из справочника 3.2. У `avatar.html` — детерминированно из длины seed (`username + name`), поэтому один автор всегда получает один цвет; справочник жанров тут ни при чём.

## 3.4 Применение

- **`GenreChip`** — чип жанра (размеры `sm`/`md`), цвета из `genreTheme`. Используется на карточках, странице произведения, в каталоге.
- **Жанровая полоса главной** — цветные чипы вместо плоского текстового списка (закрывает находку UX-аудита главной).
- **Индекс жанров** (`GenreIndex`) — сетка крупных жанровых карточек.

## 3.5 Совместимость

> ✅ **Решение DEC-12.** OKLCH поддерживается современными браузерами (Chrome 111+, Safari 15.4+, Firefox 113+). Поскольку аудитория — массовый веб, планировался **sRGB-fallback** через `@supports not (color: oklch(0 0 0))`.

> ⛔ **Статус DEC-12: не выполнено.** В `static_src/input.css` нет ни одного блока `@supports`, fallback отсутствует. На движке без поддержки OKLCH цвет не применится вообще: жанровые чипы, типографические обложки и аватары останутся без фона и без текстового цвета. Соответственно **NFR-41 не выполнен** (см. [09](09-nonfunctional.md)).
>
> Оценка объёма изменилась: при 15 ролях (3.3) × 12 жанров это уже не 36 значений, а 180, плюс отдельная шкала аватаров, где hue не из справочника. Ручной таблицей это не поддерживается.
>
> **Требуется решение** одного из трёх вариантов:
> 1. Сузить реестр ролей до 3–5 и сгенерировать fallback-таблицу под них.
> 2. Отказаться от fallback, подняв требование NFR-40 до браузеров с OKLCH (Chrome 111+ / Safari 15.4+ / Firefox 113+, релизы 2022-2023), и явно записать это в NFR-41.
> 3. Перенести жанровую тему в CSS-переменные на уровне `@theme` с fallback-парой на каждый токен, чтобы значения перестали жить в инлайн-стилях.
>
> До принятия решения OKLCH считается жёсткой зависимостью, а не прогрессивным улучшением.

## 3.6 Палитра наград

Награды автора (FR-PROF-06, DEC-43) — предметные иллюстрации, и цвет в них означает **ступень ценности**, а не жанр. `Genre.hue` тут ни при чём, поэтому металлы вынесены из OKLCH-реестра §3.3 в собственный закрытый список. Значения — hex, потому что это градиентные стопы внутри SVG, а не поверхности интерфейса.

Реестр закрыт так же, как §3.3: **новых металлов и новых стопов без внесения в эту таблицу быть не должно.** Иначе через три награды набор перестанет читаться как набор — а именно единство и делает его наградами, а не клипартом.

| Градиент | Стопы (0 → 1) | Где |
|----------|---------------|-----|
| `g-gold` | `#FFF3C4` · `#F7CE5B` · `#E0A424` · `#B97A12` | освещённые грани золотых наград |
| `g-gold-dk` | `#D9A32B` → `#8E5B0C` | затенённые грани, лицевая сторона постамента |
| `g-silver` | `#FBFDFF` · `#DCE4EC` · `#B2BECB` · `#8794A3` | освещённые грани серебряных |
| `g-silver-dk` | `#B7C2CE` → `#75828F` | затенённые грани |
| `g-bronze` | `#FBE0C0` · `#E3A76B` · `#C07B3C` · `#8F551F` | освещённые грани бронзовых |
| `g-bronze-dk` | `#C08046` → `#71411A` | затенённые грани |

Сверх металлов используются только два служебных цвета: `#0F172A` при `opacity .15` — падающая тень под постаментом, и `#fff` с прозрачностью 0.2-0.52 — блики. Собственных красок у эмблем нет: цветное пятно внутри награды разрушило бы металл.

**Ступень назначается смыслом, а не вкусом:** бронза — первые шаги, серебро — середина пути, золото — редкое. Золото носят только «Байқау жеңімпазы», «Редакция таңдауы» и верхняя ступень оқылым (BR-ACH-02). Позолотить всё значит обесценить золото — держит `test_stub_data.Achievements.test_gold_stays_rare`.

Свет во всём наборе один: сверху-слева. Градиенты вертикальные, блик — белый штрих по левому/верхнему краю. Плоских заливок нет специально: объём и есть разница между наградой и иконкой.
