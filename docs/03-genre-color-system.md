# 03 · Система жанровых цветов (OKLCH)

Жанровый цвет — навигационный инструмент: помогает мгновенно опознавать жанр в каталоге, на карточках и в чипах. Реализуется как детерминированная функция от тона (hue) в пространстве OKLCH.

## 3.1 Принцип

Светлота (L) и насыщенность (C) **фиксированы** для всех жанров; меняется только **hue (H)**. Это даёт визуально гармоничный набор и — главное — **гарантированный, одинаковый контраст** текста к фону для каждого жанра без ручной проверки пар.

> ✅ **Решение DEC-11.** Список из 12 жанров считается **закрытым справочником** на запуск. Произведению назначается **основной жанр (обязателен) + до одного дополнительного** (BR-12). Жанровая полоса в навигации показывает топ-жанры + пункт «Барлық жанр» (все жанры).

## 3.3 Спецификация генерации темы

Для жанра с тоном `H` вычисляются три цвета:

| Роль | Формула OKLCH | Назначение |
|------|---------------|-----------|
| `bg` | `oklch(0.96 0.04 H)` | Фон чипа/карточки — почти белый с оттенком |
| `fg` | `oklch(0.38 0.14 H)` | Текст/иконка — тёмный, насыщенный |
| `ring` | `oklch(0.86 0.08 H)` | Граница/обводка |

Жанр вне справочника → нейтральный fallback: `bg rgb(243,244,246)`, `fg rgb(75,85,99)`, `ring rgb(229,231,235)`.

```js
function genreTheme(hue) {
  if (hue == null) return { bg:'rgb(243,244,246)', fg:'rgb(75,85,99)', ring:'rgb(229,231,235)' };
  return {
    bg:  `oklch(0.96 0.04 ${hue})`,
    fg:  `oklch(0.38 0.14 ${hue})`,
    ring:`oklch(0.86 0.08 ${hue})`,
  };
}
```

## 3.4 Применение

- **`GenreChip`** — чип жанра (размеры `sm`/`md`), цвета из `genreTheme`. Используется на карточках, странице произведения, в каталоге.
- **Жанровая полоса главной** — цветные чипы вместо плоского текстового списка (закрывает находку UX-аудита главной).
- **Индекс жанров** (`GenreIndex`) — сетка крупных жанровых карточек.

## 3.5 Совместимость

> ✅ **Решение DEC-12.** OKLCH поддерживается современными браузерами (Chrome 111+, Safari 15.4+, Firefox 113+). Поскольку аудитория — массовый веб, на этапе верстки добавляется **sRGB-fallback** (предвычисленные приближения hex для каждого из 12 жанров × 3 роли = 36 значений) через `@supports not (color: oklch(0 0 0))`. Это снимает риск на старых устройствах.
