Внутри самих пунктов иконки по смыслу: глаз, шестерня, урна. Зачем меню. Из списка нельзя было ни посмотреть работу глазами читателя, ни открыть баптаулар, ни удалить — любое из этих действий стоило захода в «Басқару». При этом «посмотреть на сайте» для опубликованной работы — самое частое желание автора. «Сайтта қарау» показывается только для публичных статусов: у черновика и работы на модерации публичной страницы нет. Проверка идёт через `story.is_public` (PUBLIC_STATUSES), а не по литералу 'Published' — иначе пункт пропал бы у всех сериалов разом (DEC-37). {% endcomment %}
