{% comment %} TagChip (docs/ui.md). Нейтральный slate-чип для UGC-тега. Отличается от цветного `genre_chip` (OKLCH per-genre) намеренно — жанры и теги визуально не должны конкурировать. Параметры: tag — объект Tag (имеет .slug, .name, .status) href — куда вести (default: /tag// для accepted; '#' для pending) size — 'sm' (text-xs, min-h 32, default) | 'md' (text-sm, min-h 40) min-h держит тап-зону: чип остаётся текстовым (без фона, чтобы не спорить с genre_chip), но высота строки 16px давала цель ниже даже минимума WCAG 2.5.8. Визуально размер шрифта не меняется — растёт только hit-area. Pending-статус определяется автоматически по tag.status. Фильтрация видимости pending для нечитающего автора — в `tag_list.html`. {% endcomment %} {% with sz=size|default:"sm" %} {# Для accepted-тегов генерируем URL; для pending — link останется undefined и firstof отдаст '#' #} {% if tag.status == 'accepted' %}{% url 'core:tag_detail' slug=tag.slug as accepted_link %}{% endif %} #{{ tag.name }} {% if tag.status == 'pending' %} проверкада {% endif %} {% endwith %}
