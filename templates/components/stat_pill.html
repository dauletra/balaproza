{% comment %} StatPill (docs/04.3) — иконка + значение для метрик произведения. Параметры: icon — thumbs-up | eye | message-caption | ... value — число/строка для глаза (обычно через compact_count или spaced) label — полная озвучка пилюли, включая число: «4 821 ұнату». `label` обязателен везде, где пилюля несёт данные. Иконка декоративная, а значение помечено aria-hidden, чтобы скринридер не читал голое число, — без подписи метрика исчезала из озвучки целиком, и карточка автора звучала как «Таң алдында, Жазылып жатыр, Бөлім, Басқару», без единой цифры. Раньше подпись висела как `aria-label` на этом же и всё равно не доходила: у role=generic имя не выставляется.
