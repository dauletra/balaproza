{% comment %} ShareButton — кнопка «Бөлісу» с двумя режимами: - Мобайл (Android/iOS с navigator.share): нативный Web Share API, компактный системный шит с мессенджерами именно этого телефона. - Всё остальное (десктоп, включая Windows/Edge с их собственным Web Share — он тянет вообще всё, что зарегистрировано в системе как получатель шаринга: Zoom, Outlook, контакты, и это не фильтруется со стороны сайта): открывает share_modal.html через событие 'open-share' — только Telegram / WhatsApp / прямая ссылка. Поэтому проверяем не факт поддержки API, а мобильную ОС. share_modal.html подключается один раз на странице, отдельно от кнопки (см. story_detail.html, contest_detail.html) — так же, как report_modal. Параметры: url — абсолютный/относительный URL (обязательно) title — заголовок шеринга (string) label — текст кнопки (default: "Бөлісу") wrap_cls — доп. классы обёртки (опц., напр. "flex-1" в ряду действий) btn_cls — доп. классы кнопки (опц., напр. "w-full justify-center") tone — 'light' (default, белая кнопка на светлом) | 'on-dark' (прозрачная на тёмной афише конкурса). Отдельный параметр, а не приписка в `btn_cls`: `bg-white` и `bg-white/15` — утилиты одного свойства, и какая победит, решает порядок в собранном CSS, а не порядок в атрибуте Использование: {% include "components/share_button.html" with url=request.build_absolute_uri title=story.title %} {% endcomment %} {% with btn_label=label|default:"Бөлісу" %}
