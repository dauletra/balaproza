{% comment %} FormatCard (docs/ui.md) — выбор формата произведения карточкой. Параметры: value — single | serial label — заголовок карточки hint — что увидит читатель при таком выборе icon — имя иконки из спрайта checked — boolean name — имя группы (default "format") Почему карточка, а не RadioOption. Формат — самое дорогое решение автора: он определяет читательскую страницу целиком — оглавление и переходы между бөлімдер против цельного текста (docs/ui.md). Парой радио между аннотацией и жанром оно было подано слабее, чем выбор жанра, хотя жанр меняется одним кликом, а формат перестраивает страницу. Подпись говорит, что увидит **читатель**, а не как называется поле: «Көп бөлімді шығарма» описывает работу, а выбирать автору проще по последствию. {% endcomment %} {% with rid="format-"|add:value nm=name|default:"format" %} {% endwith %}
